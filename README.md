# Радиоплан

Защищённый планировщик смен ПЭТ/КТ и контроля активности РФП.

## Что реализовано

- авторизация с ролями администратора и оператора;
- конфигурируемый список аппаратов и неограниченное число сканеров;
- отдельные смены F-18 и Ga-68, пациенты, временная шкала и расчёт остаточной активности;
- подтверждение записи оператором или администратором с записью в журнал аудита;
- AES-256-GCM для номера пациента и веса в PostgreSQL, Argon2id для паролей;
- отчёт по смене в PDF, который формируется локально внутри API.

Расчёт — вспомогательный инструмент. Перед введением РФП необходим контроль специалистом.

## Запуск через Docker

Скопируйте `.env.example` в `.env`, затем задайте уникальные значения:

- `POSTGRES_PASSWORD`;
- `SETUP_TOKEN` — одноразовый токен для создания первого администратора;
- `ENCRYPTION_KEY` — Base64-представление ровно 32 байтов. Например: `openssl rand -base64 32`;
- `QUESTPDF_LICENSE` — тип лицензии QuestPDF. `Community` подходит для индивидуального использования и организаций с годовой выручкой до $1M.

```bash
docker compose up --build -d
```

Откройте `http://localhost`, создайте первого администратора с `SETUP_TOKEN`, затем работайте через интерфейс. Для домена измените `:80` в `Caddyfile` на доменное имя: Caddy автоматически выпустит TLS-сертификат.

## Локальная разработка интерфейса

```powershell
cd apps/web
npm install
npm run dev
```
